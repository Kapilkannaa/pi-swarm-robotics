# Contributing

Preserve direct laptop control and keep the Pi worker outside the actuation path.
Use a branch, explain the change and run pytest before requesting review. Never
commit config.toml, Wi-Fi headers, tokens, raw camera recordings or firmware binaries.

Do not label simulated results as hardware measurements. Add evidence mode, date,
seed and assumptions when recording results. Treat marker ID and firmware bot ID
as independent settings. Physical tests require supervised commissioning.
